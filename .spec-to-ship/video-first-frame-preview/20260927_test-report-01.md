# 视频卡片首帧预览 测试报告

- 日期：2026-09-27
- 需求：卡片中的文件为视频格式时，预览区显示视频第一帧，方便快速识别内容。
- 源码版本：工作区基于 main（6582f22）；本次改动未提交部分为下方「改动范围」所列 4 个文件。工作区另含与本任务无关的既有未提交修改（AGENTS.md、HistoryStore.swift、FeatureStoreTests.swift、_reports/），不纳入本次交付提交。

## 改动范围

- `WPaste/Domain/ClipboardItem.swift`：新增 `FileReference.isVideo`（按扩展名 UTType 判断是否 conforms to `public.movie`，实测覆盖 mp4/mov/m4v/avi/webm，不含 mp3/m4a 等纯音频）。
- `WPaste/Features/History/CardContentViews.swift`：`FilesCardContent` 在文件全部为视频时，用 `AVAssetImageGenerator` 异步取 0 秒首帧，应用视频自带方向变换，限制最长边 512 解码；取帧失败或文件缺失时保持原有文件图标回退。使用 macOS 13+ 的 `image(at:) async` API，无弃用警告。
- `WPasteTests/Domain/ClipboardItemTests.swift`：新增 `fileReferenceDetectsVideoTypes`。
- `WPasteTests/Features/ClipboardCardViewTests.swift`：新增 `videoFileShowsFirstFrameThumbnail`（AVAssetWriter 现场生成 640×360 纯蓝 H.264 .mov，验证卡片出现预览图、尺寸 ≤512、保持 16:9、中心像素为蓝）；`missingCorruptAndNonImageFilesKeepFallback` 增加 `broken.mov` 回退用例。
